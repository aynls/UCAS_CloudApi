# 共享模型面板与 Codex 兼容性：实现及验收

实现分支：`codex/model-availability-20261002`。本次完成本地实现、构建及样例浏览器验收；未部署腾讯云、未执行真实上游推理请求。服务器和受保护服务未变更。

后续发布已获用户授权并完成，见 [发布记录](2026-10-02-model-panel-release.md)。下文保留本地验收时的范围与证据。

## 页面与指标

- 模型选择放在主要位置；默认按当前项目过去 24 小时的成功 API 请求数排序，按个人 API 密钥过滤可选模型。调用量是项目汇总，不是用户点赞或实时可用率。
- 24 个一小时格子只显示成功证据：有成功记录为绿色，无记录为中性灰色。失败、取消、playground、手动测试不计入。按 Request 行计数，重试执行不会重复累计；时间按请求创建时间分桶，仅纳入已完成请求。
- 复用现有公开渠道测试，普通项目成员可以点击。配置模型别名与渠道模型映射通过真实候选关系解析，保留当前密钥的渠道范围。结果只代表所选渠道模型及测试协议。
- 专门测试采用一小时有效期；所有已匹配启用路线都有近期失败测试，且没有可能更新的成功证据时，才移入可展开的次要区域。单个路线失败、陈旧结果、测试进行中或缺失信息均不会判定模型整体不可用。
- 对最初计划做了一个保守调整：缺少候选映射本身保留“待确认”，不直接下沉，避免把配置别名或旧服务端缺字段误认为没有可用渠道。24 小时和一小时是本版可调整默认值，不是用户强制阈值。
- 下方保留现有完整贡献者卡片：署名、渠道、全部支持模型、原有备注、专门测试结果、期限、额度和有效用量。指南、额度和模型能力通过展开保留。删除被替换的旧模型卡片和大号统计卡片组件。
- 新增数据仅为项目权限校验后的聚合数与安全的渠道/模型标识；不公开请求正文、密钥、凭据、用户调用明细。不新增表、后台轮询任务或日志持久化。
